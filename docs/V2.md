# V2.0 · 街区回声

## 可互动的夜班店铺

顾客从侧门走入柜台，呼吸和眨眼；聊天时摆手，拒绝报价时摇头，成交或放弃后离场。门扇开合，商品随交易转移，霓虹、雨幕、窗外交通和热饮蒸汽持续变化。更新报价使用 DOM patch 保留舞台节点，动画不承担资金或库存结算。

- **点击顾客 / 聊聊来历**：每位一次，耐心 +1，卖家的心理底价下降约 3%，买家的心理上限上升约 3%。
- **请杯热饮**：每位一次，花费 10 ₡，耐心最多恢复并增加 2 点，上限 10。
- **点击柜台物品 / 拿起观察**：每位一次，描述外观；有鉴定仪时显示真伪。观察不直接改变价值或赠送物品。
- **点击门口**：当前顾客离开后接待下一位。
- **点击收音机**：打开街区故事；点击霓虹招牌会得到光效回应。
- **报价快捷键**：±10 和市场价填入，不会自动提交报价。

动画期间资金已结算并保存。刷新不会重新发钱、重复入库或复活离场顾客。系统偏好减少动态效果时跳过移动，所有操作仍可完成。

## 会回访的剧情

| 日期 | 来访 | 选择的实际结果 |
| --- | --- | --- |
| 1 | 雨夜的寄件人 | 借 60 ₡ 车费、信任 +2，或免费指路 |
| 3 | 整条街暗了三秒 | 40 ₡ 修电网、信任 +1、当日后续顾客耐心 +1，或继续正常营业 |
| 5 | 那张写了名字的收据 | 根据第 1 天的选择收到 150 / 35 ₡，或把酬谢留给街区、信任 +2 |
| 7 | 只开一晚的旧物集 | 花 80 ₡ 获得当日回收率 88%，或保留现金 |
| 10 | 替旧时代留一份底稿 | 收购过至少三种商品可分享记录获得 120 ₡、信任 +1，商品仍归玩家 |
| 14 | 零点之后，还有灯 | 信任 ≥3 获得 180 ₡，否则 60 ₡；也可转赠换取信任 |
| 14 天后每三天 | 午夜点歌台 | 花 20 ₡ 留热饮、信任 +1、当日新顾客耐心 +1，或免费借出路标 |

可先去营业，再返回选择；未回应就打烊会记为错过，不会自动扣钱。效果与费用在选择前明确显示。每次选择带事件 ID，重复点击、刷新或旧按钮不会重复结算。故事收支计入现金账本，不混入商品利润；临时效果在次日清除。

## 图鉴与声音

十种旧物各有档案，记录初见日期、见过的最佳品质、是否收购过、是否用仪器鉴定过。同种商品的实例可能有不同品质和真伪；图鉴不是当前库存清单，出售不会丢失进度。

门铃、成交、报价回应、聊天、观察和故事音效均由 Web Audio 现场合成，不下载外部音频。默认关闭；顶部按钮手动启动。设置可调整音量和独立的雨声/电流环境声偏好，后台暂停，声音失败不阻塞交易。

## V1 兼容

`src/core.js:migrate` 先验证 V1，复制后补充 V2 数据；保留现金、库存、租金、日期、随机数和谈判状态。存储键不变，内容版本更新为 2。`src/storage.js:save` 首次覆盖 V1 前保存原始快照，失败时保持原档。

自动存档、手动快照、重置备份和 JSON 导入均可读取 V1。已存在库存和当前顾客用于补充图鉴；旧版本未保存的历史商品不会被虚构补齐。原来已经停业的存档仍然停业。正在缓存 V1 的窗口应先正常保存并关闭所有游戏窗口，再重新打开以启用新 Service Worker；不需要清理网站数据。

在「存档 / 设置」中可直接导出升级前 V1 原始备份。音频支持由浏览器能力决定；本地 Windows Playwright WebKit 未暴露 Web Audio 接口，因此该环境验证静音降级，Chromium 验证实际音频上下文和合成节点。真实 iPad 的扬声器听感和主屏幕安装仍需实机检查。
